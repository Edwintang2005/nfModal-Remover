NF Modal Remover

A Safari extension for Mac that hides .nf-modal pop-ups, only on the websites you choose.

Getting started

  1. Open NF Modal Remover once from Applications.
  2. In Safari, go to Settings → Extensions and tick NF Modal Remover.
  3. Visit a site with the pop-up, click the red icon in the toolbar, and turn on This site.
  4. If Safari asks for permission, choose Always Allow on This Website.

Common questions

I can't see the toolbar icon

Right-click Safari's toolbar, choose Customize Toolbar, and drag the NF Modal Remover icon in.

The pop-up still appears on a site

Check that the site is in the popup's "Active on" list and that Safari has permission to use the extension there (Safari → Settings → Extensions → NF Modal Remover → Edit Websites). The extension only removes elements with the nf-modal class; a site that uses a different pop-up won't be affected.

Does it cover subdomains?

Yes. Adding example.com also covers www.example.com, shop.example.com and so on.

How do I stop it on a site?

Open the popup and turn off This site, or click × next to the site in the list. Reload the page to see it as normal.

Does it collect my data?

No. See the privacy policy.
